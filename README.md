## 这是什么

一个面向中国出海 DTC 品牌老板的「经营诊断助手」产品的高保真可点击原型，覆盖从**每日异常检测 → 原因归因 → 策略建议 → 执行闭环 → 每周复盘**的完整产品流程。这是产品设计阶段的演示产物，用于向目标客户做 15 分钟产品演示。

## 产品背景

出海品牌的经营数据分散在 Shopify、Amazon、Meta、Google 等多个平台，老板每周只能看到"卖了多少"，很难快速回答"为什么掉了、该做什么"。这个产品的思路是：

- **每日检测**：自动对比实际销售额与预期正常范围，异常才报警；
- **归因闭合**：把销售额变化拆解成逐项相加能对账的原因（程序规则计算 + AI 调查推断，两种确定级别在界面上明确区分）；
- **策略落地**：每条归因给出带护栏检查（调价幅度、毛利底线、预算上限等）的可执行方案，关键参数可改、护栏即时重查；
- **执行闭环**：按平台能力分三档执行（一键执行 / 直达后台 / 生成任务），执行后自动回读确认、可撤回，台账只追加；
- **越用越准**：每条策略到期复盘"预计 vs 实际"，沉淀为店铺自己的经验库。

## 怎么看这个原型

- 左侧边栏顶部可切换 **工作台 / Agent** 两种模式；
- 核心页是「归因与方案」：每条归因固定为 *判断 → 编号信源 [1][2][3]（点开看数字来源与算法）→ My Plan（可改参数、可选备选）*；右下角的 Agent 气泡跟随选中的归因；
- 右上角「演示控制」可以：切换身份（老板 / 独立站组 / Amazon 组 / 投放组，各角色可见内容不同）、模拟 5 种异常状态（加载中、缺数据、未过审核、核对失败、回读超时）、一键重置；
- 内置 5 个可走通的演示场景：断货补货、广告素材疲劳、广告成本突涨（推荐"不动"）、Amazon 竞品降价（AI 调查）、独立站竞品降价（一键调价与撤回）。

## 说明

- 所有数据为合成剧本数据，品牌「营地户外」及竞品均为虚构；
- 执行与回读均为页面模拟，不连接任何真实平台；AI 回答为预写内容，不现场调用模型；
- 单文件 HTML（内联 CSS/JS），无网络与构建依赖，下载后双击即可本地打开。
